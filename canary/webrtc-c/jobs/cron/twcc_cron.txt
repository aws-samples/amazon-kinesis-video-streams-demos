# TWCC network-shaped storage canary cron entry (RPi5).
#
# Exercises the media service's TWCC (bitrate adaptation) on the ingest path:
# the master's uplink is shaped by a netns mid-path router + tc/netem (cycling
# GOOD -> MEDIUM -> CONGESTING -> BAD -> RECOVERING), so the TWCC-aware master's
# encoder must track the available bandwidth. Verified via CloudWatch metrics
# (OutgoingBitrate / EstimatedBitrate / DelayTrend) under RUNNER_LABEL=TwccShaped.
#
# Prerequisites (see docs/rpi5-setup-sop.md "Phase 10"):
#   - Runner seeded from storage_runner.groovy / gamma_runner.groovy WITH the
#     CANARY_TWCC_SHAPING param (added alongside this entry).
#   - A DEDICATED RPi5 node labeled rpi5-twcc, onboarded via rpi-onboard.sh (which
#     installs /usr/local/bin/twcc-net + /etc/sudoers.d/twcc-canary + iptables +
#     gstreamer1.0-plugins-ugly). Dedicated because CANARY_MEDIA_SOURCE=testsrc is a
#     gst=ON build; sharing a node with a disk-path (gst=OFF) scenario forces a full
#     rebuild every run (the .build-flags stamp flips).
#   - The channel-owner account (232283333863) is on the media-service
#     twcc-shadow-mode allowlist for the target stage/region, else TWCC won't
#     negotiate (offer omits the transport-wide-cc extmap).
#   - ENDPOINT + AWS_DEFAULT_REGION point at the allowlisted stack. Leave ENDPOINT
#     empty for the default (prod) control plane in AWS_DEFAULT_REGION.
#
# Pi defaults baked in: STS_DURATION_SECONDS=3600 (role-chaining cap),
# VIEWER_WAIT_MINUTES=120 (from-scratch gst build far exceeds the 20-min default).
# Isolate TWCC metrics via RUNNER_LABEL; keep SCENARIO_LABEL a consumer-recognized
# value (StorageWithViewer). Until the TWCC port is merged to the canary's mainline,
# GIT_HASH=twcc-canary.

# TwccShaped (duration 156s ~3min, every 12 min) — shaped master + JS viewer
H/12 * * * * %RUNNER_LABEL=TwccShaped;SCENARIO_LABEL=StorageWithViewer;JS_STORAGE_VIEWER_JOIN=true;CANARY_TWCC_SHAPING=true;CANARY_MEDIA_SOURCE=testsrc;TWCC_MIN_VIDEO_BITRATE_KBPS=100;TWCC_STAGE_SECONDS=20;TWCC_THROTTLE_LOSS=0;DURATION_IN_SECONDS=156;MASTER_NODE_LABEL=rpi5-twcc;STORAGE_VIEWER_NODE_LABEL=webrtc-storage-viewer;AWS_DEFAULT_REGION=us-east-1;ENDPOINT=;VIEWER_WAIT_MINUTES=120;STS_DURATION_SECONDS=3600;GIT_HASH=twcc-canary
